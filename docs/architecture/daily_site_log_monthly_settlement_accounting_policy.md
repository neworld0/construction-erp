# 공사일보·월 정산 회계·세무 운영정책 v1.0

> 승인일: 2026-08-26. 이 정책은 공사일보·월 정산 확장 설계의 업무 기준이다. 개별 계약·세금 신고의 예외는 세무대리인 및 계약 담당자의 확정이 우선한다.

## 1. 비용 발생일 정책

- 원가는 지급일이 아니라 재화·용역을 검수하거나 사용이 확정된 날에 인식한다.
- 자재는 현장/창고 인수·검수일, 장비는 실제 사용 완료 또는 월 사용 확정일, 일용노무는 작업일, 하도급은 검수기성 확정일을 발생일로 한다.
- 발생일, 증빙일, 지급예정일, 실제지급일을 별도 보관한다.
- 증빙이 지연되면 발생월에는 `PENDING_EVIDENCE` 미지급금으로 잡고, 수취 뒤 금액·VAT·거래처를 확정한다.

## 2. VAT 공제 정책

| 상태 | 경영 원가 | VAT 신고 | 처리 기준 |
|---|---|---|---|
| 공제 가능 확정 | 공급가액 | 공제 반영 | 적격 증빙과 사업 관련성 확인 |
| 공제 불가 | 총액 | 공제 제외 | 불공제 사유 보관 |
| 면세/비과세/인건비 | VAT 없음 또는 총액 | 공제 제외 | 지급 성격·법정 근거 보관 |
| 증빙 검토중 | 총액 잠정 | 반영 보류 | 증빙 수취/세무 검토 필요 |

## 3. 발주처 직불 정책

- 발주처가 협력사·하수급인에게 직접 지급한 사실이 증빙으로 확정된 때에만 처리한다.
- `BillingSettlementAllocation(OWNER_DIRECT)`으로 기성 미수금과 협력사 미지급금을 같은 금액만큼 줄인다.
- 회사 CashAccount/CashEvent를 만들지 않으며, 은행 현금잔액에 반영하지 않는다.
- 원 기성 세금계산서와 협력사 세금계산서의 VAT 처리는 직불 자체와 독립이다.

## 4. 하도급 기성·청구·지급 정책

- 계약: 하도급 계약금액과 선급금·기성공제·유보금 조건을 스냅샷으로 관리한다.
- 기성: 현장/HQ 검수로 시공분이 확정된 날 원가와 미지급금을 인식한다.
- 청구: 협력사 청구서·세금계산서 수취 상태다.
- 지급: 회사 지급 또는 발주처 직불로 미지급금을 감소시킨다. 새 원가를 생성하지 않는다.
- 원수급 기성청구와 하도급 기성은 자동으로 같다고 처리하지 않는다.

## 5. 월마감 통제

- 미수취 증빙, VAT 검토중, 미지급금, 발주처 직불 예정 건은 정산서에 별도 표시한다.
- 마감 확정 전에는 기성 미수금·미지급금·직불 상계·VAT 상태의 대사를 통과해야 한다.
- 마감 후 변경은 원본 직접 수정이 아니라 정정 요청과 새 정산 스냅샷으로 처리한다.
