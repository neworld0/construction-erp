CODEX MOBILE PROMPT — FIELD 전용

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

목적 (Goal)
기존 Construction ERP의 FIELD 기능을 모바일 전용 UX로 재구성한다.
•	모바일은 입력•확인 전용
•	승인•마감•관리 기능은 절대 포함하지 않는다
•	“한 손 / 1분 / 실수 방지”를 최우선 기준으로 구현한다
________________________________________
전제 조건 (Do NOT Change)
•	기존 모델, 승인 흐름, 마감 로직 변경 금지
•	기존 PC FIELD 화면 유지
•	모바일은 UI/URL 분리만 수행
•	권한(RBAC), AuditLog, Closing 규칙 그대로 사용
________________________________________
1. URL / 구조 설계
다음 모바일 전용 URL을 추가한다.
/app/field/mobile/                # 모바일 홈
/app/field/mobile/progress/       # 진행률 입력
/app/field/mobile/reports/        # 보고서 입력
/app/field/mobile/costs/          # 원가 입력
/app/field/mobile/inventory/issue # 자재 투입
/app/field/mobile/labor/timesheet # 출역부 입력
•	FIELD 권한만 접근 가능
•	PC에서는 접근 불가
•	모바일 User-Agent 또는 명시 URL 기준
________________________________________
2. 모바일 홈 화면 (/app/field/mobile/)
목적
“오늘 뭐 입력해야 하지?”를 3초 안에 해결
구성 요소
•	프로젝트명 (자동 선택: 최근 사용)
•	오늘 날짜 (고정)
•	오늘 상태 카드
o	진행률: 미제출 / 제출
o	보고서: 미작성 / 임시 / 제출
o	원가: 미입력 / 임시 / 제출
•	바로가기 버튼 (큰 버튼 4개)
o	진행률 입력
o	보고서 작성
o	원가 입력
o	자재 투입
________________________________________
3. 공통 모바일 UX 규칙 (모든 화면 적용)
입력 규칙
•	숫자 필드 → 숫자 키패드
•	금액 → 정수만 저장, 천 단위 콤마 표시
•	진행률 → 0~100 제한, 소수점 1자리
버튼 규칙
•	하단 고정 CTA
[임시저장]   [제출]
•	버튼 높이 ≥ 48px
•	제출 버튼 클릭 시 확인 모달 필수
제출 확인 모달 (공통)
제출 후에는 수정할 수 없습니다.

작업: {{WBS}}
금액/진행률/제목: {{value}}
날짜: {{date}}

[취소]   [제출]
________________________________________
4. 진행률 입력 화면
필드
•	WBS 선택 (드롭다운)
•	진행률 (%) 입력
•	메모 (선택)
기능
•	“어제 값 복사” 버튼 추가
•	임시저장 가능
•	제출 후 수정 불가
•	승인 상태는 읽기 전용으로 표시
________________________________________
5. 보고서 입력 화면
정의 변경 (중요)
•	보고서는 원가 증빙이 아닌 독립 보고
•	같은 날 여러 건 허용
필드
•	제목
•	내용 (멀티라인)
•	파일 첨부
o	사진 촬영
o	파일 선택
제약
•	제출 후 수정 불가
•	권한 없는 보고서는 목록에 노출 금지
________________________________________
6. 원가 입력 화면
필드
•	CBS 자동완성 (비활성 CBS 제외)
•	금액 (정수)
•	메모
•	증빙 파일 (필수)
제약
•	증빙 없으면 제출 버튼 비활성화
•	제출 후 입력 폼 초기화
•	승인 전까지는 조회만 가능
________________________________________
7. 자재 투입 화면
정책 (모바일 특화)
•	임시저장 없음
•	즉시 제출만 허용
필드
•	품목
•	수량
•	CBS
→ 제출 시 재고 감소 + 원가 자동 생성
________________________________________
8. 출역부 입력 화면
필드
•	직종
•	인원(일수)
규칙
•	단가 자동 스냅샷
•	제출 후 수정 불가
•	승인 상태는 읽기 전용 표시
________________________________________
9. 모바일 보안 정책
•	일정 시간 미사용 시 자동 로그아웃
•	뒤로가기 캐시 차단
•	제출 후 URL 직접 접근 차단
