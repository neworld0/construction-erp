/app/ceo/ CEO 대시보드 KPI 카드에 아래 2가지를 추가한다.
1.	KPI 카드에 증감(▲▼) 표시
•	기준일(또는 필터 기준) 기준으로 전월 대비(기본) 또는 전주 대비(옵션) 증감을 계산해 표시

•	평균 진행률(실적) vs 계약 경과율(시간 경과) 비교
•	결과로 상태 배지 표시(🟢정상/🟠지연/🔴위험)

•	기존 대시보드의 카드/차트 레이아웃 최대한 유지(문구/보조라인 추가)

2) 기준 기간 정의 (기본 정책)
•	기준일(base_date)은 화면의 기준일(현재 UI 상단 날짜)
•	증감 비교 기간 기본: “전월 동일 누계”
o	base_month_start ~ base_date 누계
o	vs prev_month_start ~ prev_month_equivalent_date 누계
•	옵션(추후): 전주 비교는 함수 옵션으로만 둔다.
중요
•	마감(CLOSE)된 월은 “확정값”, 미마감은 “추정/미정” 로직을 그대로 사용
•	증감 계산 시, 가능한 경우 “기준선만(확정)” 토글이 켜져 있으면 확정 데이터만 사용
________________________________________
3) 증감 계산 규칙
각 KPI마다 아래 값을 만든다:
•	value_current: 현재 기간 누계(또는 현재값)
•	value_prev: 비교 기간 누계
•	delta = value_current - value_prev
•	delta_pct = delta / max(abs(value_prev), epsilon) (0 나눗셈 방지)
•	trend = "up" if delta > 0 else "down" if delta < 0 else "flat"
표시 포맷:
•	금액형: ▲ +1.2억 / ▼ -0.6억
•	비율형(이익률): ▲ +0.6%p
•	flat이면 — 0
단위:
•	KRW 표시는 기존 포맷과 동일하게 유지하되, 증감 라인은 “요약(억/만)” 단위를 사용해도 됨.
•	소수점은 1자리 또는 0자리로 통일
________________________________________
4) 진행률 vs 계약 경과율
4-1) 계약 경과율 계산
각 프로젝트에 대해:
•	계약 시작일 start_date
•	계약 완료일 end_date
•	기준일 base_date
경과율:
•	elapsed = clamp((base_date - start_date) / (end_date - start_date), 0, 1)
•	%로 변환
프로젝트별 진행률은 기존 로직(현장 입력/승인 기반)을 그대로 사용.
평균 진행률은 기존 “평균 진행률” 카드 값(avg_progress_pct) 사용.
4-2) 비교 결과 (상태 배지)
•	gap = avg_progress_pct - elapsed_pct
•	상태:
o	🟢 정상: gap >= -5%p
o	🟠 지연: -15%p < gap < -5%p
o	🔴 위험: gap <= -15%p
표시 예:
•	평균 진행률 18.67%
•	계약 경과 24.00%
•	상태 🟠 지연 (gap -5.33%p)
UI 표기
평균 진행률 카드에 보조 라인 2개 추가:
•	계약 경과 24.0%
•	상태: 지연 (-5.3%p)

6) 성능/쿼리 최적화(필수)
•	증감 계산에 필요한 집계는 최소 쿼리로 수행
•	가능하면 동일 테이블은 월별 기간별로 한 번에 집계
•	프로젝트별 루프에서 N+1 쿼리 금지
•	util 함수는 QuerySet을 받아 group aggregate 가능하도록 구성
