[CODEX-PROMPT] HQ 업무용 To-do 카드 추가 (HQ Dashboard)

목표
- HQ 대시보드(/app/hq/) 상단(또는 첫 섹션)에 “오늘의 HQ 업무(To-do)” 카드 1개를 추가한다.
- To-do는 실제로 해야 하는 운영 업무(승인/마감/리스크/누락)를 자동 집계해 보여준다.
- 기존 설계(승인/리스크/마감/권한/감사로그)는 유지하고, “표시용 집계 + 링크”만 추가한다.
- DB 스키마 변경 없이 구현한다.

전제(변경 금지)
- 기존 모델/상태/권한/마감(CLOSE)/감사로그 로직 변경 금지
- 기존 HQ 화면 URL 유지: /app/hq/
- 기존 HQ 대시보드 레이아웃/톤 유지(카드 1개 추가)
- 모바일 최적화는 필수가 아니지만 버튼/링크는 클릭 가능해야 함

구현 범위
- HQ dashboard view: hq/views.py 또는 해당 view(컨텍스트에 todo_items 추가)
- HQ 템플릿: hq_home.html (To-do 카드 렌더링)
- (권장) hq/todo.py 유틸: 집계/문구 생성 순수 함수

To-do 카드 구성(필수)
- 카드 타이틀: “오늘의 HQ 업무”
- 카드 본문: 체크리스트 형태(최대 5개 항목)
- 각 항목은 다음 요소 포함:
  - 상태 아이콘(🔴/🟠/🟢)
  - 텍스트(짧게)
  - 카운트(n건)
  - 링크(클릭 시 해당 업무 화면으로 이동)

집계 항목 정의(최소 4개, 최대 5개)

1) 승인 대기(핵심)
- 정의: HQ가 처리해야 할 승인 대기 건수(예: DailyReport/CostActual/Timesheet/Transfer 등)
- 표시:
  - 🔴 n>=5
  - 🟠 1~4
  - 🟢 0
- 링크:
  - HQ 승인함/Inbox 페이지가 있으면 그곳으로
  - 없으면 /app/hq/ 로 이동하되, 앵커(#inbox) 또는 쿼리(?tab=inbox) 지원(가능하면)

2) 48시간 이상 미처리 리스크(중요)
- 정의: OPEN 리스크 중 detected_at 기준 48h+ 경과
- 표시:
  - 🔴 n>0
  - 🟢 0
- 링크:
  - /app/hq/risks/ 또는 리스크 상세/목록(없으면 HQ 대시보드 리스크 섹션 앵커로)

3) 마감 임박(월 마감) (중요)
- 정의: 이번 달 ClosingPeriod가 OPEN이고, “마감 예정일(또는 월말)”까지 D일 이하인 프로젝트 수
- D 기본값: 3일 (설정값이 있으면 그 값 사용)
- 표시:
  - 🔴 n>0 이면 “마감 임박 n건”
  - 🟢 0
- 링크:
  - 월 마감 관리 화면(이미 있는 버튼/URL로 연결)

※ 마감 예정일 정보가 없다면 대체 규칙:
- “현재 월이 OPEN” + “미승인/미제출 잔존”이 있으면 임박으로 간주(단, 과도한 경보는 피함)

4) 미제출/미입력 누락(운영 품질)
- 정의: ‘오늘 기준’ FIELD에서 제출해야 하는데 누락된 건을 간단히 집계
  - 예: 진행률 미제출 프로젝트 수, 출역부 미제출 수(선택)
- 표시:
  - 🟠 n>0 (주의)
  - 🟢 0
- 링크:
  - 프로젝트 목록 또는 해당 누락 점검 화면(없으면 /app/hq/projects/ 로)

5) 데이터 품질 경고(선택)
- 정의: KPI 계산에 “미정/추정” 비율이 높은 프로젝트 수(있으면)
- 표시:
  - 🟠 n>0
- 링크:
  - KPI 품질 상세 또는 CEO 품질 배지 상세(없으면 HQ 대시보드 관련 섹션 앵커)

문구 템플릿(한국어, 짧게)
- 승인 대기: “승인 대기 {n}건 처리”
- 장기 리스크: “48시간+ 미해결 리스크 {n}건”
- 마감 임박: “월 마감 임박 {n}건”
- 누락 점검: “오늘 미제출/누락 {n}건 점검”
- 품질 경고(선택): “KPI 품질 주의 {n}개 프로젝트”

정렬 규칙(중요)
- 위험도가 높은 순으로 위에:
  1) 🔴 항목
  2) 🟠 항목
  3) 🟢 항목(가능하면 숨김 또는 마지막)
- 단, 승인 대기는 항상 상단에 두는 것을 권장(업무 흐름상)

UI 요구사항
- 카드 상단 오른쪽에 “모두 보기” 링크(선택):
  - HQ 프로젝트 목록 또는 HQ 운영 페이지로
- 항목이 모두 🟢(0건)일 때:
  - “오늘의 HQ 업무가 모두 정상입니다.” 문구 표시
  - 체크리스트는 숨기거나 1~2줄만 표시

성능 요구
- 대시보드 로딩에 영향을 주지 않도록 쿼리를 최소화
- 가능한 경우 기존에 이미 대시보드에서 집계한 승인/리스크 수를 재사용
- N+1 쿼리 금지

완료 기준(Acceptance)
- /app/hq/ 상단에 “오늘의 HQ 업무” 카드가 표시된다.
- 승인/리스크/마감/누락 항목이 자동 집계되어 n건으로 표시된다.
- 각 항목 클릭 시 해당 화면으로 이동한다.
- 모든 항목이 0건이면 “정상” 메시지가 나온다.
- 기존 승인/리스크/마감 로직은 변경되지 않는다.

간단 테스트
1) 승인 대기 2건 만들기 → 🟠 “승인 대기 2건 처리” 표시
2) 리스크 detected_at 60h짜리 1건 → 🔴 “48시간+ … 1건”
3) 마감 OPEN + 임박 조건 충족 → 🔴/🟠 임박 표시
4) 모두 0 → “오늘의 HQ 업무가 모두 정상입니다.” 표시

이 요구사항에 따라:
(1) HQ dashboard 컨텍스트에 todo_items를 생성하고
(2) 템플릿에 체크리스트 카드로 렌더링하여 구현을 완료하세요.
