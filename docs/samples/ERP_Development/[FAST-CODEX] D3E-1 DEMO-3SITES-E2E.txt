[FAST-CODEX] D3E-1: DEMO-3SITES-E2E Seed 커맨드 스캐폴드 + Discovery(모델/필드/URL/상태값) 확정

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

STOP RULE
- DB 스키마 변경 금지
- 수정 파일 최대 6개
- 서버 실행/테스트 0회(스캐폴드/Discovery만)
- 기능 확장 금지, 이번 단계는 “틀과 매핑표”만 만든다

목표
1) management command 생성:
   core/management/commands/seed_demo_3sites_e2e.py
2) Discovery로 아래를 코드 내 “매핑 상수/헬퍼”로 확정:
   - 승인 모델명/상태값(APPROVED/REJECTED/SUBMITTED/DRAFT) 실제 값
   - 마감 모델(ClosingPeriod) 생성/상태 전환 API/함수 위치
   - 정정(Adjustment) 생성/승인 흐름 엔티티 위치
   - 첨부(Attachment/Evidence) 연결 방식(모델/필드)
   - 재고: Warehouse/Location/InventoryLedger/Stock/Transfer 존재 여부
   - 자재투입: IssueToWork(INV-5) 존재 여부(없으면 스킵할 fallback 준비)
   - 출역: Timesheet/LaborRole/단가표/PayrollAllocation 존재 여부

3) 커맨드 옵션:
   --month YYYY-MM (기본 2026-02)
   --reset (선택)
   --dry-run (선택, DB 저장 없이 Discovery 출력)

산출물
- seed_demo_3sites_e2e.py: 아직 데이터 생성은 최소(또는 0)로 하고,
  Discovery 결과를 콘솔에 요약 출력하는 기능까지 구현
- 내부에 “TYPE_MAP / STATUS_MAP / URL_HINTS / MODEL_HINTS” 같은 상수/주석 테이블 생성

Done 기준
- 커맨드가 실행되고(dry-run 가능),
- 프로젝트 코드베이스에 맞는 모델/상태값/연계 방식이 정리되어 출력된다.
- 다음 단계(D3E-2)에서 실제 생성 로직만 채우면 되도록 구조가 잡혀 있다.
