[FAST-CODEX] D3E-2: DEMO-3SITES-E2E (마스터+프로젝트 세팅) 생성 로직 구현

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

STOP RULE
- DB 스키마 변경 금지
- 수정 파일 최대 8개
- 서버 실행/테스트 1회
- 운영 데이터(진행률/원가/보고서/출역/재고 이벤트)는 만들지 않는다(다음 단계)

전제
- D3E-1의 Discovery 매핑을 사용한다.

기준 시나리오(고정)
- 기준 월: 2026-02
- 프로젝트 3개:
  P1: ASAN-조경1: 공원 리모델링
  P2: ASAN-토목1: 우수관 정비
  P3: ASAN-건축1: 관리동 증축
- 계약금:
  P1 3,000,000,000 / P2 2,000,000,000 / P3 800,000,000
- 기간:
  착공 2026-02-01
  준공 P1 2026-05-31 / P2 2026-04-30 / P3 2026-03-31
- 창고:
  HQ-WH, P1-WH, P2-WH, P3-WH
- 품목(ItemMaster) 20개(조경 중심)
- 직종(LaborRole) 6~8개 + 단가표
- 급여배부(PayrollAllocation) 2026-02로 1건 이상(HQ 입력 가정)

목표(생성 순서 고정)
A) 계정/권한/2FA
- 기존 seed_initial이 있으면 재사용/호출. 없으면:
  - CEO 1, HQ 2, FIELD 3~6 생성
  - FIELD는 프로젝트 배정(Assignment) 필수

B) 마스터
- Warehouse/Location 생성
- ItemMaster 생성(20+)
- LaborRole/단가표 생성
- CBS:
  - 기존 CBS 테이블/로더를 그대로 사용
  - 예산에 필요한 CBS 코드가 없으면 “이미 존재하는 조경 코드 중 활성 상태”를 우선 선택(새 CBS 생성 금지)
  - (만약 CBS가 너무 비어있다면) 최소 10개만 추가하되, 기존 정책(잠김/별칭/비활성) 준수

C) 프로젝트 등록(HQ)
- Project 생성
- ProjectContract 생성
- WBS baseline v1 생성(가능하면 APPROVED까지, 아니면 SUBMITTED 상태로 만들어 CEO 승인 Inbox에 1건 남기기)
- BudgetItem 생성(프로젝트별 10~20라인, CBS 연결)
- 계약서 첨부 1개(더미 파일 생성 후 첨부 연결)
  - 더미 파일은 코드로 생성 (txt/pdf 중 가능한 방식)
  - 첨부 연결은 D3E-1에서 파악한 Evidence/Attachment 방식으로

콘솔 요약 출력(필수)
- 생성된 프로젝트 id + HQ 등록 URL(가능하면)
- FIELD 계정별 배정 프로젝트 목록
- WBS/예산/계약서 첨부 생성 여부

Done 기준
- 3개 프로젝트가 “계약/예산/WBS/창고/마스터/계정”까지 완성
- 운영 데이터 없이도 HQ/CEO가 프로젝트 기본 화면을 확인 가능
