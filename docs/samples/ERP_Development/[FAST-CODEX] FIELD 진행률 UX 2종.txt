[FAST-CODEX] FIELD 진행률 UX 2종 (미니 바 시각화 + 오늘 미제출 알림 배너)

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

전제
- 기존 설계/URL/모델 유지
- 대상: FIELD 진행률 탭(모바일 우선, PC 공통)
- DB 스키마 변경 없이 구현
- 기존 임시저장/제출/승인/마감(CLOSE-2)/권한(RBAC)/AuditLog 로직 변경 금지
- 성능 저하/N+1 쿼리 금지

목표
1) 진행률 목록에 “미니 바(누계 시각화)” 추가: %를 막대로 직관 표시
2) “오늘 입력 미제출 알림” 배너 추가: 오늘 임시저장만 있고 제출이 없으면 상단 경고 표시

------------------------------------------------------------
1) 진행률 누계 시각화 (미니 바)
------------------------------------------------------------
요구사항
- 위치: FIELD 진행률 탭의 “최근 입력 목록(또는 진행률 목록)” 각 행/카드 내부
- 표시: 진행률 %를 미니 바로 표현 + 숫자 병기
  예) ██████░░░░  60%
- 디자인:
  - 모바일에서 한눈에 보이게 높이 6~8px 정도의 bar
  - 테마/스타일은 기존 CSS(다크 테마)와 통일
  - 색상은 기존 상태 badge 컬러 체계를 재사용하거나, 중립적 단일 색 사용(새 컬러 체계 도입 금지)

구현 상세
A) HTML/CSS 방식(권장)
- 각 row에 progress 값(0~100)을 이용해 width% 적용:
  - container: bar-bg (100% 폭)
  - fill: bar-fill (width: {progress}%)
- 숫자 표시는 bar 옆 또는 아래에 “{progress_display}%”
- progress_display는 기존 표준(소수 1자리)로 통일(앞 티켓의 가드 로직 재사용)

B) 템플릿 렌더링
- progress 값이 None이면:
  - bar 숨기고 “-” 표시

C) 접근성(권장)
- aria-label: “진행률 60퍼센트”

완료 기준
- 진행률 목록에서 %가 미니 바로 보이고, 숫자와 일치한다.
- 0%는 빈 바, 100%는 꽉 찬 바로 표현된다.

------------------------------------------------------------
2) “오늘 입력 미제출 알림” 배너
------------------------------------------------------------
요구사항
- 위치: FIELD 진행률 탭 상단(탭 콘텐츠 시작부, 입력 폼 위 또는 목록 위)
- 표시 조건(필수):
  - 오늘 날짜 기준으로 “임시저장(DRAFT)” 진행률 입력은 존재하지만,
  - “제출(SUBMITTED)” 진행률 입력이 하나도 없을 때 표시
  - 또는: 오늘 입력이 전혀 없으면 배너를 띄우지 않음(불필요한 경보 방지)
- 문구:
  - “⚠️ 오늘 진행률이 아직 제출되지 않았습니다.”
  - (선택) 보조 문구: “임시저장 내역을 확인하고 제출하세요.”
- 동작:
  - 배너 클릭 시 “임시저장 항목”이 있는 위치로 스크롤 또는 필터 적용(가능하면)
  - 최소 구현: 클릭 시 아무 동작 없어도 됨(표시가 핵심)

구현 상세
A) 서버 집계(필수, 정확도)
- FIELD 진행률 탭 컨텍스트 구성 시, 아래를 계산:
  - today = localdate()
  - has_today_draft = 오늘 date + status=DRAFT (또는 임시저장 상태) 존재?
  - has_today_submitted = 오늘 date + status=SUBMITTED 존재?
- 배너 표시 조건:
  - show_banner = has_today_draft AND NOT has_today_submitted
- RBAC:
  - FIELD는 본인/배정 프로젝트 범위 내 데이터만 카운트

B) 성능
- 존재 여부 확인은 count() 대신 exists() 사용(쿼리 최소화)
- 이미 오늘 목록을 가져오고 있다면, 그 queryset을 재사용하여 플래그 계산(추가 쿼리 줄이기)

C) 마감 정책
- CLOSE-2로 오늘 제출 자체가 차단되는 상태(마감)라면:
  - 배너 문구를 “⚠️ 현재 마감 상태로 제출할 수 없습니다.”로 바꾸거나,
  - 배너를 숨기고 입력 폼 자체에서 마감 안내를 하도록(기존 정책 우선)
  - 새 규칙 만들지 말고, 기존 마감 메시지/가드가 있으면 그것을 따름

완료 기준
- 오늘 임시저장만 있고 제출이 없으면 배너가 뜬다.
- 오늘 제출이 1건이라도 있으면 배너가 숨는다.
- 오늘 입력이 아예 없으면 배너가 뜨지 않는다.
- 권한/프로젝트 범위 밖 데이터로 인해 배너가 잘못 뜨지 않는다.

------------------------------------------------------------
파일/위치 Discovery 지시(필수)
- FIELD 진행률 탭 템플릿/뷰 위치 확인:
  - templates/field/dashboard.html (진행률 탭 block)
  - field/views.py (진행률 목록 queryset/컨텍스트 생성)
- 진행률 상태 코드(DRAFT/SUBMITTED/APPROVED/REJECTED) 실제 값 확인 후 매핑

------------------------------------------------------------
Acceptance(요약)
- 진행률 목록에 미니 바가 나타나고 값이 정확하다.
- 오늘 임시저장만 있고 제출이 없을 때만 “미제출 알림”이 상단에 표시된다.
- DB 스키마 변경 없이, N+1 없이 구현된다.
- 기존 마감/승인/권한 설계를 변경하지 않는다.

간단 테스트
- 오늘 DRAFT 1건, SUBMITTED 0건 → 배너 표시
- 오늘 DRAFT 1건, SUBMITTED 1건 → 배너 숨김
- 오늘 입력 0건 → 배너 숨김
- progress=0/60/100 각각 바 표시 확인

기존 queryset을 최대한 재사용하여 플래그와 미니 바 렌더를 추가하세요.
