[FAST-CODEX] FIELD-APPROVED-LISTS-BE: Field 승인 완료(Approved) 진행률/보고서/원가 목록 조회 API/뷰 구현 (Discovery 포함)

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

STOP RULE
- 스키마 변경 금지
- 수정 파일 제한: 최대 6개
- 테스트/서버 재시작 제한: 1회
- 기능 확장/UX 제안 금지

전제
- 승인 완료 조건은 status == APPROVED 또는 비슷한 값
- Field는 자신의 할당 프로젝트만 보도록 RBAC 적용
- Codex는 “승인 완료 판단 필드/모델명/상세 URL 패턴”을 Discovery로 찾아 구현

목표
1) /app/field/approved/ API/뷰 생성
2) Field 할당 프로젝트만 선택하여 Approved된 item만 보여줌
3) type 필터(progress/report/cost)
4) 기간 필터(from/to), 기본 최근 30일
5) 정렬: approved_at desc

Discovery 지시
1) 승인모델 확인:
   - 승인 상태를 어떻게 판단하는지
   - status 필드명, approved_at 필드명 찾기
2) 객체 타입:
   - 진행률/보고서/원가를 어떻게 구분하는지(필드명/object_type)
3) Field 할당 프로젝트 접근:
   - Field 프로젝트 배정 관계/테이블 명
   - 프로젝트 리스트 필터 방법
4) 각 원본 객체에서 summary/title/기준일을 추출하는 방법

BE 설계(예시)
projects = request.user.assignments.values_list("project_id", flat=True)
approved_qs = ApprovalRequest.objects.filter(
status="APPROVED",
project_id__in=projects,
object_type=selected_type,
approved_at__range=(from, to)
).order_by("-approved_at")


뷰 반환 내용
- id
- approved_at
- project_name
- object_id
- object_type
- summary (title/메모/진행률 값)
- attachments count

Acceptance
- 팀장/Field로 로그인했을 때 /app/field/approved/가 동작
- RBAC로 Field 할당만 필터됨
- type/기간 필터 및 정렬 정상
