[FAST-CODEX] FIELD-APPROVED-LISTS-UI: Field용 “Approved 목록” UI 템플릿 + 필터/Discovery

당신은 시니어 Django 엔지니어입니다. 리포지토리 루트는 construction-erp 입니다. 

STOP RULE
- 상세 UI 리디자인 금지(기본 템플릿 컴포넌트 재사용)
- 수정 파일 제한: 최대 8개
- 테스트/서버 재시작 제한: 1회
- 무한 스타일 제안 금지

전제
- BE 목록 API/뷰가 동작
- attachments_badge 공통 컴포넌트 사용 가능
- Codex는 “URL 패턴/템플릿 위치/한글 깨짐 요소”를 Discovery로 찾아 수정

목표
1) Field 대시보드 또는 주 메뉴에 “승인 완료 목록” 버튼 추가
2) 템플릿에 탭/필터 구현
   - 진행률 / 보고서 / 원가 탭
   - 기간 필터, 프로젝트 필터
3) 리스트 테이블 칼럼
   - 승인일(한글)
   - 프로젝트(한글)
   - 요약(한글)
   - 첨부 배지(attachment_badge)
   - 상세보기 버튼

Discovery 지시
1) Field 대시보드 템플릿 위치 탐색
2) 메뉴/탭 구조 파악
3) Filter UI 요소 위치/레이아웃 탐색
4) 목록 템플릿 리스트 구조 파악

UI 예시
[승인 완료 목록]
[진행률] [보고서] [원가]
기간: [2026-02-01] ~ [2026-02-28]
프로젝트: [P1 ▼]
| 승인일 | 프로젝트 | 요약 | 첨부 |

한글 체크
- meta charset utf-8
- 버튼/라벨/상태 한글 깨짐 확인

Acceptance
- Field 승인 완료 목록 UI 탭/필터 동작
- 한글 UI 깨짐 0
