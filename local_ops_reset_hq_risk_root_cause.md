# Root Cause

`RiskFinding #1` was generated by the demo seed flow. Its project was deleted by local reset, leaving a nullable project FK as NULL and `PROJECT#1` in the generic fields. HQ counted all OPEN findings in both its todo count and risk-card query, so the demo row remained visible.

The row is now classified as `DEMO_SEED_RISK`. It is excluded from HQ and CEO operational dashboards and is included in local reset dry-run cleanup. No destructive apply was run.
