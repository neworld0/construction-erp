## 2. 리허설 목적

본 리허설은 운영서버 점검 전에 로컬 환경에서 다음 전체 흐름을 실제 업무 순서대로 확인하기 위한 검증 시나리오입니다.

```text
기존 프로젝트 데이터 reset
→ HQ 신규 공사 등록
→ 계약내역서 v2 업로드
→ WBS/CBS/예산 기준선 생성
→ FIELD 진행률 입력
→ FIELD 출역 입력
→ HQ 노무/전자카드 업로드·대사·확정
→ 근로내용확인신고 Excel 생성
→ 일용노무비청구명세서 생성
→ CEO/HQ 대시보드 검증
→ 8월 월마감
→ 마감 후 수정 차단
→ RBAC 검증
```

이번 v2의 핵심 검증 목적은 다음입니다.

| 검증 영역 | 검증 목적 |
|---|---|
| Reset | 기존 프로젝트, stale 리스크, stale 최근 승인 표시 제거 |
| 계약내역서 import | 기업이윤 포함 계약내역서 전체 반영 |
| 예산 기준선 | 계약금액과 예산 기준선 총합계 일치 |
| CBS 매칭 | 미매칭 행이 조용히 누락되지 않는지 확인 |
| WBS 기준선 | 시작일·종료일 자동 설정 확인 |
| FIELD 진행률 | 진행률 대상 WBS만 계산되는지 확인 |
| LABPAY | 전자카드 업로드·대사·확정·신고용 Excel 생성 확인 |
| CEO/HQ 대시보드 | 계약금액, 예산, 진행률, 노무비, 리스크, 최근 승인 표시 검증 |

| 개인정보 보호 | 테스트 데이터만 사용하고 원문 개인정보 노출 방지 |

WBS-99는 진행률 입력 대상에서 제외하거나, 입력 가능하더라도 CEO 진행률 계산에서 제외해야 합니다.

### 13.2 입력 시나리오

| 일자 | WBS | 누적 진행률 | 작업 내용 |
|---|---|---:|---|
| 2026-08-14 | WBS-01 현장 준비 및 안전관리 | 30% | 현장 인수, 안전표지 설치 |
| 2026-08-17 | WBS-01 현장 준비 및 안전관리 | 100% | 안전시설 설치 완료 |

| 2026-08-20 | WBS-02 기존 포장 절삭 | 100% | 절삭 완료 |

### 13.3 진행률 계산 기준

이번 리허설의 진행률 계산 원칙은 다음입니다.

```text
CEO/FIELD 진행률 = WBS-99 제외, 진행률 적용 대상 WBS 기준
```

진행률 적용 대상 WBS의 금액 합계는 107,800,000원입니다.

| WBS | 금액 | 8월 말 누적 진행률 | 기여도 |

| WBS-01 | 13,200,000 | 100% | 12.24% |
| WBS-02 | 26,400,000 | 100% | 24.49% |
| WBS-03 | 59,400,000 | 80% | 44.08% |
| WBS-04 | 19,800,000 | 30% | 5.51% |
| WBS-05 | 13,200,000 | 0% | 0.00% |

> 주의: 위 표는 v2 정책 검증용입니다. 시스템에서 WBS별 weight가 별도로 관리되는 경우, 실제 CEO/FIELD 진행률은 “진행률 적용 대상 weight 합계 100%” 기준으로 정규화되어야 합니다. 리허설에서는 시스템이 사용하는 진행률 분모가 “계약금액 전체”인지 “진행률 적용 대상 WBS”인지 반드시 확인합니다.
